VIPSCore API Documentation

VIPSCore is the server component that hosts the models. It is accessible via VIPSCoreManager over http/REST. Models that are on the component's classpath are autodetected, indexed and made available through the REST service. The service is used by VIPSLogic when running models. It can also be contacted directly by any client.

VIPSCore is a part of NIBIO's VIPS platform for automatic pest prediction
